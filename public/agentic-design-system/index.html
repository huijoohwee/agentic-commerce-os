Governance rules

One owner

Every token, profile, guideline, component, and stable ID resolves to one accountable source.

Rights before reuse

Unknown license or permission blocks publication. A link does not transfer ownership.

Pin and roll back

Consumers bind an immutable release and digest. A successor names its predecessor.

No shadow variants

Do not add a second editable value for the same profile, token, mode, or component ID.

Design tokens

Token values stay in their native source. This catalog exposes an entry only after its owner, exact revision, digest, and reuse permission are recorded.

Brand profiles

Each profile needs a unique ID, identity owner, intended surface, and permitted-use record. No palette or identity asset is invented here.

Guidelines

Guidelines resolve to their original owner and revision. The catalog does not maintain a competing policy copy.

Accessibility contracts

Interactive records need named evidence for keyboard use, visible focus, measured contrast, zoom, reduced motion, narrow touch layouts, and offline behavior. The catalog does not imply conformance without results.
