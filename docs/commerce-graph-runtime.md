# Reference implementation — Commerce and Graph runtime composition

Commerce owns `https://airvio.co/agentic-commerce-os/`. Graph owns
`https://airvio.co/agentic-graph/`. The Commerce console exposes an optional
**Open in canvas** link using Graph's existing `openEditorWorkspace=1` query
contract. The implementation is merchant-agnostic; it does not invent buyer,
price, revenue, or independent evaluator evidence.

## Current local-first MVP scope

The accepted 2026-09-11 sprint amendment selects browser-local offer drafts and
JSON transfer at the Commerce URL. That dated checkout deferral is historical; current profile
receipts remain in the joined product plan. The navigation entrypoint reuses the existing Graph
workspace URL on an explicit click; the 2026-10-05 native component below adds local presentation reuse.
It never sends drafts, cookies or checkout state to Graph. Offline access covers
the Commerce shell, drafts and pinned component assets after cache priming; opening the full Graph
workspace requires its own connection and runtime. The historical local-first receipt cannot establish current full-Commerce provider readiness or transaction completion. The dated full-runtime investigation
below remains historical evidence for the deferred profile.

## Execution availability

The current MVP permits execution to stop while the operator Mac sleeps or is
offline. Availability independent of that Mac is a future roadmap item. The
[device-session execution host](local-host-runtime.md) implements authenticated
local execution and explicit unavailable/busy responses. This availability
decision does not waive provider, transport, trust or release evidence.

## Runtime behavior

`GRAPH_WORKSPACE_URL` is nonsecret configuration. Production and Staging use
the canonical Graph path. Local and Dev leave it empty until an operator sets
their Graph server URL. HTTPS is required except for loopback in Local/Dev;
credentials, query strings, fragments, whitespace, oversized URLs, and Commerce
self-links are rejected. Misconfiguration fails visibly instead of redirecting
users to an invented destination.

The link opens a new tab with `noopener noreferrer` and no referrer and passes no checkout, token,
merchant, claim or browser storage state. This navigation path is separate from the bounded
local component, which receives only explicit host-projected values and loads no Graph workspace. Merchant-specific storefront pages do not add this
operator navigation. Closed delivery surfaces omit the link. Graph continues
to own its canvas, storage, editor, and authorization. This is workspace
navigation; it does not automatically import a Commerce workflow into Graph.

A future document embed must use Graph's published document-scoped iframe
contract in `docs/documents/agentic-graph-embeddability-contract.md` in the Graph
repository. It requires an actual shared document, rather than embedding the
entire operator application or copying its canvas into Commerce.

## Native data-view component — reference implementation

**Accepted scope, 2026-10-05:** the user selected “Embed the native table in Commerce.”
The native-reuse `edge-commerce-agent-mvp@0.21.0` join and Graph's `PLAN-AGENTIC-GRAPH-AGENTIC-COMMERCE-PLATFORM-PRD-TAD-ADR-MVP-GTM@0.4.0`
bind this source change. Vendor/Admin/project offer lists and selected-record properties use the
Graph-owned native table core. The existing Commerce edit/review button opens its native editor.
This read-only presentation adapter adds no inventory, channel, media or checkout feature.

| Boundary | Single owner / invariant |
|---|---|
| Design policy | Graph `docs/documents/agentic-graph-ui-ux-design-document.md#global-appearance-authority`; no competing `DESIGN.md` or brand guideline. |
| Visual values | Graph `grph-shared/ui/themeTokens`, native token/typography generators, `selectedRowClasses` and responsive/sticky table classes. Commerce retains shell identity and maps semantic shell slots to generated values; it does not author an alternate table palette. |
| Table rendering | Graph `canvas/src/features/markdown/ui/MarkdownDataViewTableCore.tsx`; native row and column wrappers delegate the same structure. Portable list and property views do not recreate it downstream. |
| Host data/effects | Commerce drafts/IndexedDB, revision checks, selection, filters, review and editor remain authoritative. A lazy projection maps records to bounded display strings and explicit callbacks. |
| Portable lifecycle | Graph `dataViewBrowserAdapter.tsx` exports `mountDataView(target, state)` → `update(fullState)` / `destroy()`; a target within the host ShadowRoot isolates native component CSS. |
| Source/export | Graph `canvas/scripts/build-data-view-adapter.mjs` generates local module, component CSS, token CSS and provenance; rebuild after source fixes, never hand-edit generated bytes. |

State is `{columns: {id, name}[], rows: {id, cells: string[]}[], selectedRowId?, onActivateRow?,
orientation?: "rows" | "columns", ariaLabel?}`. Exported `DATA_VIEW_BROWSER_LIMITS` caps 64 columns,
1,000 rows, 4,096 characters/cell, 128/ID, 256/name or label and 196,608 serialized UTF-8 bytes.
Commerce's existing 100-draft bound stays narrower. Lists initially reveal 32 rows, then 32 more on
explicit action; one selected record uses column orientation. Values render as text, not HTML.
Validation precedes update; malformed inputs cannot silently replace a good state or widen authority.

Mount only when a relevant surface opens, update from current host state and destroy on replacement
or exit. A late import must check the current generation before mounting; stale selection or destroyed
views cannot reappear. Preserve explicit loading, failed import, storage failure/stale snapshot, empty
and no-match states. Fail visibly with the existing recovery action, without a copied-table fallback.
No draft data, credentials, private notes or workflow output is sent to a Graph service. The adapter
closure has no Graph stores, media loader, network request, persistence, model or execution owner.
MCP/WebMCP and `/ @ #` continue to call their existing Commerce schemas and handlers.

Build from the admitted Graph source with its locked dependencies:

```sh
node canvas/scripts/build-data-view-adapter.mjs --out-dir <artifact-directory>
```
